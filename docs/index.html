      What runs where

      Every hour (GitHub Actions)

      Ingest ESO carbon intensity and Open-Meteo weather for 5 GB sites. Check drift and live error. Retrain if needed, then run the champion/challenger gate in the MLflow registry. Forecast, publish this console, and trigger CI when a new champion is promoted.

      Every commit (CI)

      Lint and unit tests. A model quality gate (must beat persistence). kubeconform, terraform validate and promtool. Docker build, Trivy scan, smoke test and push to GHCR. Then a rollout to an ephemeral Kubernetes cluster (kind) and a call through the service.

      Serving

      FastAPI with Prometheus metrics and hot model reload. Kubernetes manifests with rolling updates, HPA, PDB and probes. Terraform for AWS App Runner, plus Docker Compose with MLflow, Prometheus, Grafana and alert rules. A Jenkinsfile with a manual approval gate and automatic rollback.

      Data: National Grid ESO Carbon Intensity API (carbonintensity.org.uk), Open-Meteo. Forecasts are for demonstration.
